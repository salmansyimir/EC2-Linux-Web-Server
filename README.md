# Project 3: AWS EC2 Linux Web Server with Apache

## Project Overview
This project demonstrates how to deploy a Linux web server on Amazon EC2 using Apache HTTP Server (httpd). The goal is to understand the fundamentals of cloud computing, Linux server administration, and network security in AWS.

## Objectives
- Launch and configure a Linux EC2 instance.
- Connect to the instance and execute basic Linux commands.
- Install and configure Apache HTTP Server (httpd).
- Host a basic webpage and test HTTP connectivity.

## AWS Services & Technologies
- Amazon EC2
- Linux
- Apache HTTP Server (httpd)
- SSH
- HTTP

## Implementation Steps
1. Launched a Linux EC2 instance.
2. Connected to the instance using SSH.
3. Installed and started Apache HTTP Server.
4. Created a basic HTML webpage.
5. Accessed the website using the EC2 instance's public IPv4 address.

## Key Learnings
- Understanding EC2 instances and cloud compute resources.
- Practicing Linux command-line operations.
- Understanding how Apache serves web content.
- Learning how security groups control inbound network traffic.
- Understanding the relationship between public IP addresses, ports, and web access.

## Security & Cost Considerations

- Reviewed AWS billing considerations to minimize unexpected charges.
